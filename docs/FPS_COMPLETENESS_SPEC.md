# FPS 完成度基準

- 状態: rc.4 ローカル受け入れ中
- 対象: デスクトップ向けブラウザ、キーボード・マウスおよびゲームパッド
- 基準日: 2026-07-20

## 目的

本作を「3D の戦闘デモ」ではなく、入力、移動、遮蔽、射撃結果、情報提示が一貫したサーバー権威型ヒーロー FPS として成立させる。見た目の豪華さより先に、プレイヤーが予測できる物理と正しい戦闘結果を保証する。

## コア不変条件

1. プレイヤー、ダッシュ、ノックバック、引き寄せ、巻き戻し、スポーンは、同じ空間問い合わせと安全移動経路を通る。
2. 壁、床、天井、閉じた扉、遮蔽物は、移動、射線、爆発、範囲効果に対して同じ意味を持つ。
3. 通常の弾丸は最初の遮蔽物で止まる。貫通は材質、厚さ、残存エネルギーを明示した武器だけに許可する。
4. ヒット、ヘッドショット、回復、状態異常、撃破はサーバーが確定し、クライアントは未確定結果を確定表示しない。
5. サーバーの入力 ACK は受信済みではなく適用済みコマンドを示す。入力エッジを上書きで消失させない。
6. 競技用の表示面とゲームプレイ用衝突は一つの設計図から生成し、外部GLBは明示的な装飾として両者を変更しない。
7. ポインターロック解除、フォーカス喪失、メニュー表示中は戦闘入力を中立化する。
8. 揺れ、ボブ、フラッシュなどを 0 にした設定は、実際の出力も 0 にする。

## 優先度と受け入れ条件

### P0: FPS としての正しさ

| 領域 | 必須仕様 | 自動受け入れ条件 |
| --- | --- | --- |
| キャラクター移動 | カプセル相当の連続衝突、めり込み復旧、壁スライド、角処理、床・天井・段差・立ち上がり余白 | 薄い壁を越える大変位、負方向、斜め角、天井ジャンプ、低天井立ち上がり、段差を決定論的に試験 |
| 能力移動 | ダッシュ、押し引き、ワープ、巻き戻しも安全移動 API を使用 | 全移動能力を壁際で実行し、遮蔽外への貫通と場外移動がない |
| 射撃 | 最初の静的遮蔽物・動的遮蔽物・対象のうち最短 TOI で解決 | 壁越し命中なし、頭部と胴体は真に近い交点を採用、銃口直前の遮蔽物で停止 |
| 爆発・範囲効果 | 候補抽出後に視線判定。直撃対象への二重加算なし | 壁越し爆発・回復・状態異常なし、直撃＋爆風の重複なし |
| 発射体 | 1 tick の移動区間を sweep。半径を持つ弾は半径込み | 高速弾が薄い壁を抜けず、低 FPS 相当でも結果が一致 |
| 入力コマンド | 有界キュー、順序適用、適用済み ACK、入力リース | 同 tick 前の複数入力で移動・射撃エッジが欠落せず、無通信時に入力が張り付かない |
| マップ | 同じ設計図から決定論的に生成した表示面と構造物プロキシ | 既知の壁、全スポーン、主要ルート、場外境界を検査し、全solidが正体積で表示形状と一致 |

### P1: 操作感と試合情報

| 領域 | 必須仕様 | 受け入れ条件 |
| --- | --- | --- |
| マウス | 数値感度、ポインターロック、対応環境では raw input、ロック解除時は入力停止 | 感度保存、ESC 後の視点・射撃停止、再ロック復帰 |
| ゲームパッド | デッドゾーン後の連続アナログ値と独立した視点感度 | 小入力が全速にならず、斜め入力を正規化 |
| カメラ・武器 | ADS、FOV 遷移、武器別反動、ボブ・揺れ・フラッシュ軽減 | 30/60/120 Hz で時間ベースの挙動が同等、軽減 0 が完全無効 |
| 戦闘フィードバック | 即時の発砲感、サーバー確定ヒット表示、方向被弾、材質別着弾 | 予測発砲を二重再生せず、誤ヒットマーカーなし |
| 試合 UI | 目的、OT、役割、現在の仕事、キルフィード、リスポーン、スコア、通信 | 初見プレイヤーが HUD のみで現在目標と推奨行動を説明できる |
| チーム機能 | ワールドピンと短文通知。競技ルールの 1/2/2 編成を維持し、選択不可理由と各ロールの仕事を明示 | ピンが味方に位置・種別・寿命付きで同期し、スパム制限される。編成制約を UI とサーバーが同じ定義から判定 |
| スポーン | 占有検査、安全な代替スポーン、短い保護と解除条件 | 敵の直射線内・構造物内に出ず、攻撃開始で保護解除 |

### P2: 本番品質の継続改善

- キャラクターと武器の専用モデル、リグ、移動・射撃・リロード・能力アニメーション。
- 材質タグに基づく足音、着弾、跳弾、遮蔽音、空間音響。
- GLB の圧縮、LOD、セル分割、遮蔽カリング、インスタンシング、エフェクトのプール化。
- 複数実機・複数ブラウザでの長時間試合、20 人相当の負荷、パケット損失・ジッタ・再接続試験。
- 色覚、字幕、リバインド、ホールド・トグル、画面効果を含む設定画面の完成。

P2 はアート制作や複数人の実機検証を含むため、ローカル自動試験だけで「完了」と判定しない。

## 空間問い合わせの共通語彙

- `MotionSweep`: 形状を始点から終点へ動かした最初の衝突時刻、法線、対象を返す。
- `VisibilityTrace`: 始点と終点の間の最初の blocking hit を返す。
- `OverlapQuery`: 形状と重なる候補を安定順で返す。
- `AttackResolution`: 静的形状、動的形状、キャラクター候補を同じ距離軸で比較し、確定結果を一度だけ適用する。
- `SafePlacement`: スポーン、ワープ、立ち上がり先が占有されていないことを検査し、必要なら安全な代替位置を選ぶ。

各問い合わせは `hit`, `fraction`, `point`, `normal`, `kind`, `id`, `material` を返せる形を基準とし、呼び出し側が個別に 2D 距離や軸反転を再実装しない。

## マップ検証

1. 床、壁、柱、階段、天井、扉を共有blueprintの有限primitiveとして記述し、表示面とgameplay proxyを同時生成する。
2. 外部GLBの全ノード階層・座標系・単位・ハッシュは固定するが、明示的に採用したprimitive以外は競技衝突へ入れない。
3. 装飾、小物、透明面、極小三角形は`collision:false`とし、権利・出典・ハッシュを版管理する。
4. 全スポーンから主要目的地までカプセル走査し、到達性、頭上余白、段差、場外漏れを報告する。
5. 表示メッシュ頂点に対するプロキシ被覆率と、被覆されない構造物名を CI 成果物へ出す。

## ネットワーク検証

- 63 Hz の固定サーバー tick に対し、入力生成 30/60/120 Hz で同じコマンド列の結果が一致する。
- 遅延 0/40/100/200 ms、ジッタ、重複、並べ替え、1/5/10% 損失で、入力エッジ欠落、ACK 先行、永続入力がない。
- クライアント予測は最後の適用済み ACK 状態から未 ACK コマンドを共有移動ロジックで再適用する。
- 表示用補間量をユーザーが無制限に操作して、サーバーの巻き戻し窓を偽装できない。

## 性能ゲート

以下は普遍的な業界値ではなく、本プロジェクトの初期ゲートとする。

- 1080p 標準: frame time p95 16.7 ms 未満、p99 25 ms 未満、draw calls p95 350 以下。
- 720p 低設定: frame time p95 33.3 ms 未満。
- 10 分試合後に active geometry、texture、particle、audio voice が無制限増加しない。
- 平均 FPS だけで合否を判断せず、長いフレーム、GC、GPU/CPU 時間、描画数、メモリを記録する。

## 完了判定

「ローカル完成」は全自動試験、headless、WebSocket smoke、実ブラウザ smoke、既知貫通シナリオ、性能計測が通った状態とする。「本番完成」はそれに加え、対象ブラウザ・対象 GPU・複数クライアントの実機試合と操作性評価を通した状態とする。
