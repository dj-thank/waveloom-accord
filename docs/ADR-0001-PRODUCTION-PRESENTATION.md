# ADR-0001: ゲームルールとプレゼンテーション品質を分離する

- 状態: Accepted
- 日付: 2026-07-19

## 文脈

『篝合』の frozen 仕様は、ラウンド、目標、18 ヒーロー、能力、ロール構成を定義済みである。本番候補化では視覚・音響・HUD を大幅に改善する一方、演出変更によってサーバー権威の戦闘結果や正式編成を変えると、バランスと再現性を失う。

## 決定

1. 戦闘、編成、状態遷移、CT、ダメージはサーバーを唯一の権威とする。
2. クライアントの `render`、`combat_audio`、`combat_guidance` はスナップショットとイベントから表現を生成し、勝敗結果を決めない。
3. ロール枠は共有ルールモジュールに置き、サーバー検証と UI 表示が同じ 1/2/2 定義を使う。
4. 音響はユーザー操作後に初期化し、外部音源なしのプロシージャル音を Production Candidate の基準とする。
5. 高負荷表現は、DPR、影解像度、パーティクル数、reduced-motion で上限管理する。
6. 許諾済みの `chicken gun fruzer mine` GLBはプレゼンテーション層で読み込み、作者表示・CC BY 4.0・SHA-256を同梱する。読込失敗や表示差によって権威当たり判定は変えない。

## 結果

- 演出を交換・高品質化しても、ネットワークルールとテスト済み戦闘を維持できる。
- クライアント表示が壊れても、無効な編成をサーバー側で拒否できる。
- 現在の許諾済み鉱山GLBとプロシージャル補助表現から、将来の写実PBRアセットや収録音へ段階的に置換できる。
- クライアントは厳密な観戦リプレイではなく補間表示であるため、将来の競技用途ではイベント時刻とリプレイ基盤を追加する必要がある。
