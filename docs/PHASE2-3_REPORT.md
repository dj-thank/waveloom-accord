## 4. レビュー指摘への対応

**修正済み（実装中に発見）**:
1. **§7延長が到達不能だった（凍結仕様の内部矛盾）** — §4の「敵の有効関与で甕停止」と§7の「甕100%到達時に敵関与中なら延長」が同一tick評価で排他となり、延長がデッドコード化（テストエージェントが総当たりプローブで実証）。凍結ルールの「矛盾修正のみ許可」に基づき**仮想甕方式**で修正し、ルール文書をv0.2.1に改訂（敵の関与のみが満了を妨げている間は内部の仮想甕が進行し、その満了時点で敵関与中なら延長発生・甕100%固定）。回帰テスト3件追加。
2. 満弾時のリロード入力で弾が1発消費されるサーバーバグ（クライアント実装エージェントが発見）→修正。
3. 480秒上限が延長中のラウンドを打ち切るバグ→延長中は§7の終了条件のみ適用に修正。
4. ボットの落水スタック（橋から落ちると復帰不能）→壁衝突時の速度消去・実変位ベースのスタック検知・渚経由の復帰経路・橋の縁石追加で解消。

**多視点レビュー後に修正（2026-07-19）**:

| 重要度 | 指摘 | 対応 |
|---|---|---|
| critical | 切断・再接続後のrestartで接続IDが旧値のまま残る | 接続状態を可変オブジェクト化し、IDとsocket索引を原子的に再割当。旧Worldの遅延引継ぎも世代ガードで無効化 |
| major | 480秒を越えた延長の奪還直後に旧占有陣がcap勝利 | 一度でも甕100%へ到達したラウンドでは通常cap判定を再適用しない |
| major | §3主要状態遷移・在圏者リスト・cap勝利理由が§9ログに不足 | `obj_state_transition`、`occupants`（ID/team/effective）、理由付き `obj_round_win` を追加 |
| major | 降下中に橋縁石へ埋まり歩行不能 | 空中の段差マージンを無効化し、めり込み状態からの脱出移動も許可 |
| major | 表示→非表示で30fpsフォールバックが開始しない | visibility両方向を管理する `FrameDriver` に置換、トレーサー上限200も追加 |
| minor | seed・R1サイド割当がログにない | `match_start` をログ先頭に追加 |
| minor | restart予約競合・未参加socketからのrestart | restart時に予約解除し、参加済み接続だけを許可 |
| minor | tick accumulatorが無上限 | 最大8tick分に制限し、余剰時間を明示的にスキップ |
| minor | `/client/../` による静的配信のパストラバーサル | 正規化後に `client/` / `shared/` 配下であることを検証 |
| minor | 延長途中参加時の復帰補正表示が0秒 | 権威値と開始時刻をobjective snapshotへ追加 |
| minor | リスポーン位置を他プレイヤー補間が横断表示 | 5m超または生死切替時は即時スナップ |

**レビュー検証が上限で中断していた3件もローカル再現後に修正**:

- 急角度レイが胴体円柱の上下面を素通り → 上下円盤との交差判定を追加。
- 浅瀬の回復灯珠2個が岩内部 → 到達可能な浅瀬座標へ移動。
- `resolveAxis` がめり込みからの脱出方向も拒否 → 内部状態では水平移動による脱出を許可。

**残存（後続Phaseへ送る既知事項）**:
- リロードは簡易実装（開始時に弾数を満タン化し完了時刻まで発射禁止。観測可能な挙動は仕様と一致するがHUD上は即時満タンに見える）
- スナップショットはJSON平文で全プレイヤー位置を含む（壁裏情報の秘匿・帯域最適化はPhase 7のランク対応時に検討）
- ボットは仕様書§21の完全版ではない（ロール差なし。Phase 6で本実装）
- ブラウザの非表示タブではsetIntervalフォールバック（30fps）で入力送信・演出寿命処理を継続する（ブラウザのタイマースロットリング範囲内）
