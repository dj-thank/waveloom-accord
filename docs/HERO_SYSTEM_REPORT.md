# 18ヒーロー・能力システム実装報告

## 結論

『篝合』の既存Phase 2〜3プロトタイプへ、18人のキャラクター、固有武器、パッシブ、副攻撃、能力1・2、必殺技を追加し、キャラクター選択、戦闘HUD、3D表現、ボット、WebSocket同期まで接続した。

本実装は「潮占」1モード・「大潮井」1マップで全18人を操作可能にするリファレンス実装である。製品版全体の4モード・8マップ・ランク・再接続・練習場・リプレイは含まない。

## 仕様忠実度

凍結設計書で完全な数値キットが定義されている6人は、詳細章を概要・仮スキーマより優先した。

- ザイル: 575 HP、3m刺突70、投射攻撃、鎖長資源、0.9秒の手繰り寄せ、20m/sの巻き戻し、繋留環。
- ヴェスタ: 550 HP、1.6秒チャージ50→130、灯圧6→25消費、0.8秒後12/s回復、偏光野の初期・維持消費、0.4秒予兆後の敵弾散乱。
- アサギ: 250 HP、3×22、HS44、21発、2.8秒再装填、HUD連動する5標定と時間減衰、点睛HS100。
- ツバクロ: 200 HP、勢い0→100に応じて威力28→44、連射1.2→3.0/s、再装填1.4→0.9秒、灯桟と刺さった刃の呼び羽。
- ツヅリ: 225 HP、1針60回復、最大4針、静止1秒＋45/s変換、3針以上のまとめ縫い、針数と弾倉を同期する糸繰り。
- コヨミ: 200 HP、耐久60の破壊可能な香炉と領域、刻3/s、20m内の味方能力使用ごと+4、早回し・遅延・閏刻。

残る12人は概要章の中核メカニクスを実際に対戦できる挙動へした。完全な製品数値が凍結されていないため、CD、射程、効果量の一部はプロトタイプ調整値である。

## システム構成

### データ

`shared/data/heroes.js` を唯一のロスター定義とし、18人の表示情報、基礎体力、移動倍率、武器、パッシブ、4アクションを格納する。クライアント、サーバー、ボット、テストは同じ定義を参照する。

### サーバー権威シミュレーション

- 能力ライフサイクル: 入力エッジ、コスト、予兆、発動、回復、クールダウン、必殺ゲージ。
- 戦闘: 即着弾、三点バースト、散弾、近接、チャージ、弾道投射、跳弾、爆発、回復弾。
- 効果: 障壁、投射物減速領域、回復領域、DoT、減速、HUD抑制、標定、ダメージ肩代わり、一時シールド。
- 固有資源: 鎖長、鋳金、灯圧、波高、標定、勢い、油量、刻、痛みなど。
- 状態・弾体・障壁・領域をスナップショットへ含め、死亡後も発射済み弾体を前方シミュレーションする。

### クライアント

- ロール別18人一覧、武器・パッシブ・4アクション説明、選択確定、準備中／死亡中の変更。
- HP、シールド、弾数、固有資源、4アクション状態、必殺%、味方情報、キルフィード。
- 18種類の非色依存シルエット、味方輪郭、領域・障壁・弾体、予兆・発動Cue。
- 375px幅からのレスポンシブ配置、フォーカス表示、ARIA live、`prefers-reduced-motion`。
- KBMと標準Gamepadの入力統合。Pointer Lockを拒否する埋め込みブラウザでは、カーソル移動照準へ自動フォールバックする。

### 通信・ボット

- `join`で初期`heroId`を受理し、`select`を成功／拒否理由付きで応答する。
- 全入力を既知キー、厳密boolean、有限角度、単調seq、最大220ms補間へ検証する。
- 各陣5人・全10人を強制し、送信バッファ過多時は古いスナップショットを積み増さない。
- ボットも`World.queueInput()`を通り、18人それぞれの主武器・4アクション、役割別間合い、支援回復、必殺判断を持つ。

## 検証

- Nodeテスト: 157件すべて成功（ヒーロー、提供GLB、描画、音響、ガイダンス、固定編成、本番設定、配備契約を含む）。
- 18人72アクション: 制御シナリオですべて発動し、未処理behaviorなし。
- クライアント描画: 18種類のシルエット、領域・障壁・弾体、予兆、bounded pool、軽減モーションを契約テスト。
- 通信: join/select、入力検証、seq、10人上限、backpressure、restartを契約テスト。
- ボット: 18人の行動、全18必殺、各4スロット、回復、press/release edgeをテスト。
- Headless: 2 seed・18/18人を循環し、BO3完走、撃破、通常能力、必殺技、回復、目標確保を確認。

1000試合soakはコマンドとして用意しているが、今回の通常検証では実行していない。

```powershell
node tools/headless.js --soak --quiet
```

## 既知の境界

- 詳細仕様6人でも、製品版アニメーション／音響、曲面・高さを含む複雑な形状衝突、一部の任意キャンセルは抽象化している。予兆中死亡の必殺技50%返還は実装済み。
- 残る12人は概要から作ったプレイアブル実装であり、将来の完全数値仕様に合わせて再調整が必要。
- 現在のクイック相当ルールでは同キャラクター重複を許可する。
- 1モード・1マップのローカル対戦プロトタイプであり、認証やインターネット公開を前提とする本番サーバーではない。
